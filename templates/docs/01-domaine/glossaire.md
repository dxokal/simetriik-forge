# Glossaire — langage ubiquitaire

Statut : Vivant (mis à jour à chaque atelier)

Un terme = une définition = un nom technique. Les synonymes sont listés pour être **bannis**.

| Terme métier | Définition | Contexte | Nom technique | Synonymes à éviter | Exemple |
|---|---|---|---|---|---|
| Demande | Requête formelle d'un usager pour obtenir [prestation] | Instruction | `Application` | dossier, requête | Demande n° DEM-2026-00042 |
| Usager | Personne physique ou morale qui dépose une demande | Instruction | `Applicant` | client, bénéficiaire | |
| | | | | | |

## Règles de nommage
- Identifiants lisibles : `[PREFIXE]-[AAAA]-[NNNNN]`.
- Montants : suffixe `Xof` en code (`amountXof`), entiers.
